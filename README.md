# 🍅 番茄钟 (Pomodoro Timer)

一个简洁美观的桌面番茄钟应用，双击 HTML 文件即可在浏览器中使用。

## 功能

- 🍅 **专注模式**：25 分钟工作倒计时
- ☕ **短休模式**：5 分钟休息
- 🌿 **长休模式**：15 分钟长休息（每 4 个番茄自动触发）
- 🔔 **提示音**：番茄完成和休息结束时播放
- 📊 **统计**：记录今日番茄数和专注分钟数
- ⚙️ **可调设置**：所有时长、长休间隔、声音均可自定义

## 使用方式

1. 双击 `pomodoro.html` 用浏览器打开
2. 点击「开始」启动计时
3. 番茄完成后自动进入休息

## 快捷键

| 按键 | 功能 |
|------|------|
| 空格 | 开始 / 暂停 |
| R | 重置 |
| S | 跳过 |
| 1 / 2 / 3 | 切换模式 |
